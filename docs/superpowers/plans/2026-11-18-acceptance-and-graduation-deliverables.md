# 系统联调验收与毕业设计材料实施计划

> **执行要求：** 使用 `superpowers:executing-plans` 按任务顺序实施。涉及业务修复时严格执行测试先行；运行环境、截图和文档任务使用可复现命令与人工验收记录。

**目标：** 在独立 MySQL 环境中完成校园失物招领系统的全流程联调，修复发现的问题，并交付中文 README、接口文档、数据库设计图、系统截图、毕业设计论文初稿、答辩 PPT 和演示说明。

**架构：** 保持现有 Spring Boot 单体后端与 Vue 3 单页前端不变。使用独立的本地 MySQL 8 实例运行真实数据，后端通过 8080 端口提供 REST API，前端通过 5173 端口访问；自动化测试负责回归，浏览器验收负责证明主要用户流程可操作。

**技术栈：** Java 17、Spring Boot 3.5、Maven、MySQL 8、Vue 3、TypeScript、Vite、Vitest、浏览器自动化、Word（DOCX）、PowerPoint（PPTX）。

**设计依据：** `docs/superpowers/specs/2026-11-18-campus-lost-found-design.md`

## 全局约束

- 所有新增用户可见文本、接口说明、验收报告和毕业设计材料使用中文。
- 不读取、修改或重置用户现有 MySQL 实例的账号密码和业务数据。
- 不提交数据库数据目录、真实密码、JWT 密钥、依赖目录和构建产物。
- 新发现的业务缺陷必须先由失败测试稳定复现，再修改生产代码。
- 截图必须来自实际运行的系统，论文和 PPT 中不得虚构测试数据或功能。

## 重点复核

- MySQL 初始化脚本在真实 MySQL 8 中可以重复执行，且后端能够正常连接。
- 注册登录、发布、审核、检索、认领、处理申请、确认归还和通知形成完整闭环。
- 普通用户不能进入或调用管理功能，管理员可以看到统计和操作日志。
- README 与接口文档中的路径、参数、账号和启动命令与当前代码一致。
- 论文、PPT、演示说明引用的截图和功能状态与最终验收结果一致。

# 校园失物招领信息管理系统实施计划

> **执行要求：** 按任务顺序实施；业务行为遵循测试先行，每个阶段完成后运行对应测试和构建命令。

**目标：** 实现一套基于 Spring Boot、Vue 3 和 MySQL 的中文校园失物招领系统。

**架构：** 单仓库、前后端分离。后端按认证、物品、认领、通知、管理模块划分，前端按公共门户、个人中心和管理后台划分，通过 REST API 交互。

**技术栈：** Java 17、Spring Boot 3.5、Spring Security、Spring Data JPA、JWT、MySQL、H2、Vue 3、TypeScript、Vite、Pinia、Vue Router、Axios、Element Plus、Vitest。

**设计依据：** `docs/superpowers/specs/2026-11-18-campus-lost-found-design.md`

## 全局约束

- 用户可见内容和文档使用中文。
- 密码使用 BCrypt，受保护接口使用 JWT。
- 测试使用 H2，运行环境使用 MySQL。
- 不提交真实密码、令牌、数据库文件或构建产物。

## 重点复核

- 未登录用户访问受保护接口时应返回 401，而不是服务器错误。
- 普通用户调用管理员接口时应返回 403。
- 用户不能认领自己发布的信息，也不能重复提交有效认领申请。
- 非发布者不能处理认领申请，已完成流程不能被重复处理。
- 待审核或被驳回的信息不能出现在公共信息列表中。

### 任务一：工程骨架和认证

**产物：** Maven 工程、统一响应、异常处理、用户模型、注册登录、JWT 安全配置和认证测试。

**验证：** `mvn test`。

### 任务二：物品发布与检索

**产物：** 物品模型、发布与编辑、公共分页检索、详情、个人发布列表及对应测试。

**验证：** `mvn test`。

### 任务三：认领、通知和审核闭环

**产物：** 认领申请、处理流程、站内通知、管理员审核、统计与操作日志及对应测试。

**验证：** `mvn test` 和 `mvn package`。

### 任务四：Vue 3 中文前端

**产物：** 登录注册、首页检索、发布、详情、个人中心和管理后台，包含路由守卫、状态管理与接口封装。

**验证：** `npm run test` 和 `npm run build`。

### 任务五：数据库与中文文档

**产物：** MySQL 建表和演示数据脚本、README、接口说明、部署说明和环境变量示例。

**验证：** 根据 README 从全新环境执行构建命令，并检查 Git 状态不包含密钥或构建产物。

### 任务六：整体验证与交付

**产物：** 后端测试、前端测试、两端生产构建、需求逐项复核和本地提交记录。

**验证：** `mvn clean verify`、`npm ci`、`npm run test`、`npm run build`。

## 技术裁定

- 使用 Java 17 而非 Java 21：当前机器已安装 Java 17 LTS，可降低答辩环境配置成本。
- 使用 Spring Data JPA 而非 MyBatis-Plus：减少第三方版本兼容风险，并保持数据模型清晰。
- 图片首版保存 URL：将对象存储排除在核心闭环之外，后续可替换为本地或云端上传。
